02 — HTML

Tuzilma

HTML — sahifaning mazmuni va tuzilishini belgilaydi. Har bir element teg bilan yoziladi.

<!DOCTYPE html>
<html lang="uz">
  <head>
    <title>Mening sahifam</title>
  </head>
  <body>
    <h1>Salom, dunyo!</h1>
    <p>Bu mening birinchi sahifam.</p>
  </body>
</html>

03 — CSS

Dizayn va uslub

CSS rang, o'lcham, bo'shliq va joylashuvni boshqaradi. Selektor orqali elementlarga uslub beriladi.

  • Rang — color, background
  • Shrift — font-size, weight
  • Joylashuv — flex, grid
h1 {
  color: #4f46e5;
  font-size: 2rem;
  font-weight: 700;
}

04 — JavaScript

Harakat va interaktivlik

JavaScript sahifani "jonlantiradi": tugmalar, formalar, animatsiyalar va ma'lumot almashish.

const tugma = document.querySelector('#salom');

tugma.addEventListener('click', () => {
  alert('Salom, dunyo!');
});
